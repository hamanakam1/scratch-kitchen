# Kitchen Inventory

Photo naming: `<YYYY-MM-DD>_<location>_<section>.jpg`
One table per location (freezer first, then fridge, then pantry).
Fields: item, photo date, photo file, quantity estimate, bought/opened if known, still-good judgement (good / use soon / check / do not use — cook's judgement, not a food-safety guarantee), use-first rank (1 = use first).
Use-first order: fridge use soon/opened/earliest → freezer open longest → fridge good earliest → pantry opened/earliest → everything else oldest first.
Re-rank after every photo batch; never overwrite history.
