# Scratch Kitchen — Full Spec, v1

See README.md for the full v1 spec. Summary of the rules that must not drift:

- Photo in: freezer → fridge → pantry, `<YYYY-MM-DD>_<location>_<section>.jpg`
- Inventory only: no meal from an item not in inventory, no invented items
- Meal proposals: specific meal (≤40 words), ready at a specific time, for a specific person, rank 1–3 first
- Reuse, not leftovers: ingredient reused into a NEW meal, transformation named, same-meal re-serve blocked
- Share: giveaway first, cottage sale only after a compliance check is recorded (see cottage-compliance.md)
- Share board: planned → packed → offered → picked up → delivered, human coordinator, no automatic dispatch/payment in v1
- No send/sale/delivery/contact without the cook's specific approval for that specific batch
